1. Comentários, Estrutura Básica e Saída (print / println)

        
Toda instrução em Sigma termina com ponto-e-vírgula (;). O operador // é reservado exclusivamente para divisão inteira:

        
    
          
  • Comentário de linha: # ... até o fim da linha.
    • 
          
  • Comentário multi-linha: /* ... */ (rejeitado com E0001 se não fechado).
    • 
          
  • Saída Padrão: print(e1, e2, ...) escreve argumentos separados por espaço sem quebra de linha; println(e1, e2, ...) adiciona \n ao final.
    • 
          
  • Instruções de Expressão (expr;): Avaliam efeitos colaterais (como a += 1; ou i++;) silenciosamente sem poluir o stdout.
    • 
        

        
# Comentário de linha única
/* Comentário de bloco */
var q := 10 // 3;
print("Quociente: ");
println(q); # imprime "Quociente: 3"

      


      

        
2. Declaração de Variáveis e Zero-Initialization

        
Variáveis são declaradas com a palavra-chave var em três formatos (nunca é permitido var x = 10; sem tipo, erro E0002):

        
    
          
  • var nome := expr; — Inferência estática automática do tipo.
    • 
          
  • var nome : tipo = expr; — Tipo explícito verificado estaticamente (E0104 se divergir).
    • 
          
  • var nome : tipo; — Zero-Initialization (estilo Go): int = 0, float/double/decimal = 0, bool = false, char/string = "".
    • 
        

        
var a := 1_000_000;      # int inferido (separador '_' estrito)
var b : double = 2.5d;   # double explícito
var c : int;             # zero-init -> 0

      


      

        
3. Tipos Numéricos e Decimal Exato de 128 bits

        
A Sigma separa números binários IEEE 754 da aritmética base-10 exata para evitar erros silenciosos de arredondamento:

        
    
          
  • int: Inteiro de 64 bits com sinal (int64_t).
    • 
          
  • float: 32 bits IEEE 754 (padrão para reais sem sufixo como 10.0, 1e3 ou com sufixo f).
    • 
          
  • double: 64 bits IEEE 754 (sufixo obrigatório d, ex: 3.1415926535d).
    • 
          
  • decimal: Base-10 Exata de 128 bits até 38 dígitos significativos (sufixo m, ex: 0.1m + 0.2m == 0.3m). Regra de segurança: decimal opera com int e decimal, mas nunca se mistura com float/double (E0104).
    • 
        

      


      

        
4. Operações Aritméticas Unárias e Binárias

        
    
          
  • Unários (+x, -x): Preservam o tipo numérico do operando.
    • 
          
  • Binários (+, -, *, /, //, ^, %):
            
      
              
    • / (Divisão real): int / int -> float; demais promovem na hierarquia.
      • 
              
    • // (Divisão inteira): retorna sempre int com truncamento em direção a zero (-7 // 2 == -3).
      • 
              
    • % (Módulo Euclidiano): retorna resto sempre não-negativo (-7 % 2 == 1, -7.5 % 2.0 == 0.5), disponível para int, float, double e decimal.
      • 
              
    • ^ (Potenciação): associativo à direita (2 ^ 3 ^ 2 == 512) e maior precedência que - unário (-2 ^ 2 == -4).
      • 
            
    
          
    • 
        

      


      

        
5. Caracteres Unicode (char) e Strings (string)

        
    
          
  • char representa 1 code point Unicode UTF-8 completo ('A', 'ç', 'Σ', '🚀').
    • 
          
  • string suporta interpolação nativa "${expr}" para qualquer expressão.
    • 
          
  • Operações dedicadas:
            
      
              
    • char + char -> string, char + string -> string, string + char -> string, string + string -> string
      • 
              
    • char - char -> int (distância Unicode: 'z' - 'a' == 25)
      • 
              
    • char + int -> char e char - int -> char (deslocamento Unicode: 'a' + 3 == 'd')
      • 
              
    • char * int -> string e string * int -> string (repetição: "ha" * 3 == "hahaha")
      • 
            
    
          
    • 
        

      


      

        
6. Operadores Lógicos (bool) e Bitwise (int)

        
As palavras-chave not, and, xor e or operam com tipagem estrita (sem misturar bool e int):

        
    
          
  • Em bool (Lógicos): not b, a and b (curto-circuito), a xor b, a or b (curto-circuito).
    • 
          
  • Em int (Bitwise 64 bits): not x (~x), a and b (&), a xor b (^), a or b (|).
    • 
          
  • Bit Shifts em int: a << b (shift left) e a >> b (shift right aritmético com preservação do bit de sinal).
    • 
        

      


      

        
7. Operadores Relacionais, Encadeamento de 3 Operandos e Curto-Circuito

        
Os operadores ==, !=, <, >, <= e >= retornam bool:

        
    
          
  • Tipos suportados: Todos os 6 operadores para numéricos compatíveis (int/float/double ou int/decimal) e (char, char). Para (string, string) e (bool, bool), apenas == e != são permitidos.
    • 
          
  • Regras de 3 operandos (a op1 x op2 b): Permitem escrever intervalos matemáticos como 7 < x <= 30 ou 8 < 10 != 11. O termo central x é avaliado uma única vez (limite máximo de 3 operandos; 4+ operandos geram E0002).
    • 
          
  • Curto-Circuito (Short-Circuit Evaluation): Em a and b, a or b e e1 op1 e2 op2 e3, a avaliação para assim que o resultado é determinado.
    • 
        

      


      

        
8. Atribuições (=, <op>=) e Incremento/Decremento (++, --)

        
Atribuições e incremento/decremento são expressões (estilo C/JS), retornando o valor atribuído e permitindo encadeamento (a = b = 10;):

        
    
          
  • Atribuição Simples (x = y): Exige igualdade estrita de tipos typeof(x) == typeof(y) (E0104).
    • 
          
  • Atribuição Composta Aritmética e de Texto: +=, -=, *=, /=, //=, %=, ^= — exige que typeof(x <op> y) == typeof(x) (permite promoções seguras como float += int, decimal += int, char += int, string += char, string *= int; bloqueia int /= int sugerindo //=).
    • 
          
  • Atribuição Composta Lógica e Bitwise: and=, or=, xor= (para bool e int, com curto-circuito em bool para and=/or=) e <<=, >>= (para int).
    • 
          
  • Pré e Pós Incremento/Decremento (++x, --x, x++, x--): Suportados em int, float, double, decimal e char. Pré-fixados retornam o novo valor; pós-fixados retornam o valor antigo.
    •

🛠️ Toolchain & CLI Unificada (sigma)

    

      
O binário único sigma (escrito em OCaml com Dune) compartilha 100% do front-end (Lexer, Parser, Typechecker e IR) entre todas as ferramentas:

      
dune exec sigma -- run arquivo.sgm             # Executa imediatamente na Máquina Virtual (Bytecode IR)
dune exec sigma -- build arquivo.sgm -o app    # Compila para binário nativo via C99 otimizado (GCC -O3 -lm)
dune exec sigma -- check arquivo.sgm           # Valida sintaxe e tipos sem executar
dune exec sigma -- lint arquivo.sgm            # Executa o linter estático (ex: W0001 variáveis não usadas)
dune exec sigma -- debug arquivo.sgm           # Executa passo-a-passo exibindo IP, opcode, pilha e variáveis globais
dune exec sigma -- pkg init meu_projeto        # Gera manifesto de pacote sigma.toml
